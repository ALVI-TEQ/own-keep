OWNKEEP DESIGN ASSET PACK

Contents
1. launcher_icons/
   - OwnKeep_Launcher_Icon_1024.png
   - OwnKeep_Launcher_Icon_Rounded_1024.png
2. icons/png/light_mode/
   - App UI icons optimized for light backgrounds
3. icons/png/dark_mode/
   - App UI icons optimized for dark backgrounds
4. icons/svg_monochrome/
   - Monochrome SVG icons using stroke="currentColor"
5. design_tokens/
   - ownkeep_design_tokens.json
   - ownkeep_colors.csv
   - ownkeep_theme_tokens.dart
6. previews/
   - Color palette sheets
   - Icon preview sheets

Recommended usage
- Use PNG light_mode icons on light surfaces.
- Use PNG dark_mode icons on dark surfaces.
- Use SVG icons in Flutter and tint them as needed.
- Use the theme token file as your starting point for Flutter theme constants.

Core OwnKeep visual direction
- Dark First UI: #08111F background
- Primary Accent: #4F7DFF
- AI Accent: #8A5CFF
- Success: #19C37D
- Warning: #F5B400
- Danger: #FF5A5F
